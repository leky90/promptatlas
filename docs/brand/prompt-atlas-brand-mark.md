# Prompt Atlas brand mark

## Core idea

The Output/Prompt Plate encodes the product journey as a flat specimen: the large output window is seen first, the acid prompt cue is inspected second, and the small terminal carries the learned component into Composer.

## Production variants

| Variant | File | Use |
| --- | --- | --- |
| Primary | `/brand/prompt-atlas-mark-primary.svg` | Paper and light editorial surfaces |
| Reverse | `/brand/prompt-atlas-mark-reverse.svg` | Ink header and dark surfaces |
| Monochrome | `/brand/prompt-atlas-mark-mono.svg` | One-colour print and constrained output |
| Favicon 16 | `/brand/prompt-atlas-favicon-16.svg` | Optical check at 16px |
| Favicon 32 | `/brand/prompt-atlas-favicon-32.svg` | Optical check at 32px |
| Favicon 64 | `/brand/prompt-atlas-favicon-64.svg` | Manifest and 64px surfaces |
| Stable favicon | `/favicon.svg` | Browser-facing compatibility entry point |

All SVGs use the 64-unit integer grid and flat shapes. They contain no live text, fonts, gradients, shadows, transparency or provider colours.

## Palette and exclusion

- Paper `#F1EEE6`
- Ink `#121311`
- Acid action `#D8FF45`

Provider colours are evidence-only and must never enter the core symbol or wordmark. The retired split-provider favicon remains at `/brand/legacy/favicon-provider-split.svg` for rollout inspection only; no active surface may reference it.

## Size and spacing

- Approved checks: 16, 24, 32 and 64px.
- Keep at least one terminal-square of clear space around the symbol where layout allows.
- Do not redraw, round corners, add effects or collapse the output/prompt hierarchy.
- Keep the navigation wordmark as live accessible HTML text; the SVG is decorative inside the named home link.
